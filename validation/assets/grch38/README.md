# GRCh38 context assets

These files support the real-data ONT/IGV parity qualification:

- `cytoBandIdeo.txt` is the decompressed UCSC hg38 `cytoBandIdeo` table, dated 28 October 2022.
- `mane.bb` is UCSC's hg38 MANE bigGenePred asset, dated 8 December 2025.

The exact source URLs, versions, SHA-256 checksums, and licensing notes are recorded in
`validation/ont-grch38-subset.rgvgenome`. UCSC states that raw table and binary data are freely
available for public and commercial use, with attribution requested. These assets are review
context and not clinical interpretation resources.
